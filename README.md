# OKKISS 地推销售与库存管理工具

## 功能范围

### 销售录入

- 选择城市、活动日期、活动地点。
- 录入杯卖数量、瓶卖数量、试饮数量、产品名称/SKU。
- 支持一键快速录入，也支持批量补录。
- 每次保存自动写入 `data/sales_records.csv`。
- 自动统计单产品销量排行和全场畅销 TOP3。
- 支持导出当前场次 CSV，方便后续做数据透视表。

### 进销存库存管理

- 管理起泡酒产品库存：按城市仓库、活动现场两个维度统计。
- 管理物料库存：陈列物料、布置物料、冰块、水、纸巾、赠品物料。
- 记录城市仓库补货/期初、城市仓库发货到现场、现场实际消耗、未使用退回仓库、库存盘点调整。
- 自动计算当前实时库存、单场活动物料损耗率、各城市库存分布与预警。
- 每次保存自动写入 `data/inventory_movements.csv`。

### 费用明细与成本核算

- 录入产品成本：按 SKU、单价、数量记录。
- 录入物料采购费、运费、其他杂费。
- 运费支持城市入仓费、仓库到现场运费、剩余货物返程运费。
- 其他杂费支持现场搭建费、临时人工费、场地费等。
- 支持按 SKU 设置杯装售价、瓶装售价，用于自动计算销售收入。
- 自动关联当前城市、活动日期、活动地点下的销售记录，生成成本-销量对应关系。
- 自动计算单场活动总成本、单品单位成本、单场毛利率、投入产出比和 ROI。
- 支持导出当前场次成本明细 Excel。
- 每次保存自动写入 `data/cost_records.csv`，售价设置写入 `data/price_settings.csv`。

### 盈利分析与市场洞察

- 支持按城市、时间范围、SKU 多维度筛选。
- 自动生成各城市单场活动盈利排行。
- 自动生成不同 SKU 的毛利率、动销率和利润贡献对比。
- 自动生成杯卖、瓶卖、试饮转化率分析。
- 自动分析成本投入与销量的相关性。
- 自动输出经营建议：核心结论、数据拆解、风险提示、优化建议。
- 活动形式会根据活动地点关键词自动识别，例如商场/商圈、市集/展会/快闪、商超/零售、餐饮/酒吧、社区/园区。

### 权限控制

- 销售录入、库存管理：一线员工可直接访问，无需密码。
- 费用与成本、盈利分析与洞察：仅管理层可访问。
- 默认管理密码在 `app.py` 顶部的 `MANAGER_PASSWORD = "okkiss2026"` 中设置，后续可直接修改。
- 密码错误时提示「无权限访问，此功能仅对管理层开放」，并自动回到销售录入页面。
- 权限控制只限制页面访问，不改变销售、库存、费用、分析的数据保存和统计口径。

## 销售数据口径

- 销售总量 = 杯卖数量 + 瓶卖数量。
- 单产品销量排行 = 按销售总量降序排序；销售总量相同时，优先按瓶卖数量、杯卖数量、试饮数量排序。
- 全场畅销 TOP3 = 当前城市 + 当前活动日期 + 当前活动地点下，销售总量最高的 3 个 SKU。
- 试饮数量不计入销售总量，只作为现场转化参考。

## 库存数据口径

- 城市仓当前库存 = 城市仓补货/期初 + 现场退回仓库 - 城市仓发货到现场 + 城市仓盘点调整。
- 当前现场库存 = 城市仓发货到现场 - 现场实际消耗 - 未使用退回仓库 + 现场盘点调整。
- 单场活动物料损耗率/消耗率 = 现场实际消耗数量 / 城市仓发货到现场数量。
- 城市库存预警阈值：
  - 起泡酒产品：24 瓶。
  - 冰块：10 袋。
  - 水：24 瓶。
  - 纸巾：10 包。
  - 其他物料：20 件/套。
- 库存为负时，优先核对发货、消耗、退回和盘点调整记录。

## 成本核算口径

- 销售收入 = 杯卖数量 × 杯装售价 + 瓶卖数量 × 瓶装售价。
- 单场活动总成本 = 当前城市 + 当前活动日期 + 当前活动地点下的全部费用金额合计。
- 费用金额 = 单价/单次金额 × 数量/次数。
- 产品直接成本 = 产品成本中已关联 SKU 的费用金额。
- 分摊费用 = 物料采购费 + 运费 + 其他杂费 + 未关联 SKU 的产品成本。
- 分摊规则：优先按 SKU 销售收入占比分摊；如果没有售价，则按 SKU 销售数量占比分摊。
- 单品总成本 = 产品直接成本 + 分摊费用。
- 杯装单位成本 = SKU 单品总成本中分摊到杯装部分的成本 / 杯卖数量。
- 瓶装单位成本 = SKU 单品总成本中分摊到瓶装部分的成本 / 瓶卖数量。
- 单场毛利 = 销售收入 - 单场活动总成本。
- 单场毛利率 = 单场毛利 / 销售收入。
- 投入产出比 = 销售收入 / 单场活动总成本。
- ROI = 单场毛利 / 单场活动总成本。

## 盈利分析口径

- 城市单场活动盈利排行 = 按城市、活动日期、活动地点汇总后，以单场毛利降序排列。
- 活动形式 = 根据活动地点关键词自动识别，仅用于快速洞察，不替代人工活动分类。
- SKU 毛利率 = 单品毛利 / SKU 销售收入。
- SKU 动销率 = SKU 销售总量 / 库存模块中该 SKU 发货到现场数量。
- 试饮总转化率 = 销售总量 / 试饮数量。
- 杯卖转化率 = 杯卖数量 / 试饮数量。
- 瓶卖转化率 = 瓶卖数量 / 试饮数量。
- 成本投入与销量相关性 = 用每场活动的总成本和销售总量计算相关系数。
- 自动建议基于当前筛选范围内的数据生成，筛选条件不同，结论会同步变化。

## 数据透视表建议

### 销售透视表

- 行字段：产品名称/SKU。
- 值字段：杯卖数量求和、瓶卖数量求和、试饮数量求和。
- 计算字段：销售总量 = 杯卖数量 + 瓶卖数量。
- 筛选字段：城市、活动日期、活动地点。

### 库存透视表

- 行字段：城市、库存类型、库存项目。
- 列字段：活动日期、活动地点。
- 值字段：城市仓变化量求和、现场变化量求和、现场消耗数量求和、退回仓库数量求和。
- 计算字段：当前现场库存 = 现场变化量求和。

### 费用透视表

- 行字段：费用类型、费用明细、产品名称/SKU。
- 值字段：费用金额求和、数量求和。
- 筛选字段：城市、活动日期、活动地点。
- 关联字段：产品名称/SKU，可与销售明细中的产品名称/SKU 对应。

### 盈利分析透视表

- 行字段：城市、活动地点、活动日期。
- 值字段：销售收入求和、单场活动总成本求和、单场毛利求和、销售总量求和、试饮数量求和。
- 计算字段：毛利率、ROI、试饮转化率。
- SKU 分析行字段：产品名称/SKU。
- SKU 分析值字段：销售收入、单品毛利、销售总量、发货到现场数量。

## 常用 Excel 公式

销售总量：

```excel
=杯卖数量单元格+瓶卖数量单元格
```

单SKU销售占比：

```excel
=当前SKU销售总量/SUM(销售总量列)
```

试饮转化率参考：

```excel
=IF(试饮数量单元格=0,0,销售总量单元格/试饮数量单元格)
```

当前现场库存：

```excel
=城市仓发货到现场数量-现场实际消耗数量-退回仓库数量+现场盘点调整数量
```

物料损耗率/消耗率：

```excel
=IF(发货到现场数量=0,0,现场实际消耗数量/发货到现场数量)
```

单场毛利率：

```excel
=IF(销售收入=0,0,(销售收入-单场活动总成本)/销售收入)
```

投入产出比：

```excel
=IF(单场活动总成本=0,0,销售收入/单场活动总成本)
```

ROI：

```excel
=IF(单场活动总成本=0,0,(销售收入-单场活动总成本)/单场活动总成本)
```

SKU 动销率：

```excel
=IF(发货到现场数量=0,0,销售总量/发货到现场数量)
```

试饮总转化率：

```excel
=IF(试饮数量=0,0,销售总量/试饮数量)
```
